The avatars are created in OpenAI ChatGPT using the information below.

For the Cozy Nature + Progression style, I'd recommend that every bot feels like a creature, spirit, or entity from the same forest world, becoming gradually more powerful as the player climbs.

**The order below is the roster order** (D257). Each name sits at a fixed rating, and the avatars were the reason that order changed: the images have to read as increasingly powerful from top to bottom, so the names were moved to the slots where they do. Ratings and playing strength are properties of the slot and did not move.

Avatar Specifications
Resolution: 400×400 px
Style: Painterly fantasy illustration
Circular composition
Soft lighting
Detailed face/eyes
Nature-themed color palette
Transparent or simple background
Consistent art direction across all avatars

Progression Theme

The visual progression would look like:

Cute → Animal → Guardian → Mythical → Godlike

Pebble → Twig → Mote → Clover → Bramble → Willow → Vireo → Finch → Kestrel → Marlin → Ember → Basalt → Onyx → Sable → Corvus → Lyra → Quartz → Titan → Oracle → Quadrim Prime

This gives players a strong sense that they're advancing through an increasingly prestigious world rather than simply facing stronger AIs.
